UC9: Recursive Palindrome Checker
Goal :Check whether a string is a palindrome using recursion.

Flow:
Program starts
Recursive method compares characters from start and end
Function calls itself with reduced range
Base condition stops recursion
Result is printed

Key Concepts :Recursion
A technique where a method calls itself to solve smaller subproblems.

Base Condition:Stops recursion and prevents infinite calls.

Call Stack
Memory structure used to store recursive method calls.

Data Structure : Call Stack
