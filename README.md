UC5: Stack-Based Palindrome Checker
Goal

Use a Stack to reverse characters and validate palindrome.

Flow

Push characters into stack.

Pop characters in reverse order.

Compare characters and print result.

Key Concepts

Stack – Linear data structure following LIFO (Last In First Out).

Push Operation – Inserts element into stack.

Pop Operation – Removes element from stack.

Reversal Logic – Stack reverses the order naturally.
