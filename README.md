UC7: Deque-Based Optimized Palindrome Checker
Goal

Use Deque to compare characters from both ends.

Flow

Insert characters into deque.

Remove first and last characters.

Compare until deque becomes empty.

Key Concepts

Deque (Double-Ended Queue) – Allows insertion/removal from both ends.

Front and Rear Access – Direct comparison of characters.

Optimized Handling – No need for extra structures.

Data Structure

Deque
