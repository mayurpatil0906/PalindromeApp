UC11: Object-Oriented Palindrome Service
Goal :Encapsulate palindrome logic inside a dedicated service class.

Flow:
Create PalindromeChecker class
Define checkPalindrome() method
Main class calls the service method
Result is displayed

Key Concepts (OOP):
Encapsulation
Logic is hidden inside a class.
Single Responsibility Principle
Each class has one responsibility.

Reusable Code :Palindrome logic can be reused across multiple programs.

Data Structure :Internal (Array / String)
