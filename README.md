UC8: Linked List-Based Palindrome Checker
Goal

Check whether a string is a palindrome using a Singly Linked List.

Actor

User

Flow

Program starts
Input string is converted into a linked list
Second half of the linked list is reversed
First half and reversed half are compared
Result is printed

Key Concepts

Singly Linked List
A dynamic data structure where elements are connected using node references.

Node Traversal
Elements are accessed sequentially using next references.

Fast and Slow Pointer Technique
Two pointers move at different speeds to find the middle element efficiently.

In-Place Reversal
Second half of the linked list is reversed without using additional memory.
