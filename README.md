UC4: Character Array-Based Palindrome Check
Goal

Convert a string to a character array and compare characters.

Flow

Convert string to char[].

Use two-pointer technique.

Compare characters from both ends.

Key Concepts

Character Array (char[]) – Stores characters individually.

Array Indexing – Access characters using index.

Two-Pointer Technique – Start and end comparison.

Time Complexity Awareness – Efficient comparison without extra objects.
