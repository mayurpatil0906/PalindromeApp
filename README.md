UC3: Palindrome Check Using String Reverse
Goal

Check whether a string is a palindrome by reversing it.

Flow

Reverse the string using a loop.

Compare original and reversed strings.

Display result.

Key Concepts

Loop (for loop) – Iterates characters in reverse order.

String Immutability – Strings cannot be modified after creation.

String Concatenation (+) – Builds the reversed string.

equals() Method – Compares string contents.

Data Structure

String
