UC6: Queue + Stack Based Palindrome Check
Goal

Demonstrate FIFO vs LIFO behavior using Queue and Stack.

Flow

Insert characters into Queue.

Push characters into Stack.

Compare Queue dequeue with Stack pop.

Key Concepts

Queue – Linear data structure following FIFO (First In First Out).

Enqueue Operation – Insert element into queue.

Dequeue Operation – Remove element from queue.

Stack vs Queue – Demonstrates opposite behavior.

Logical Comparison – Matching dequeue and pop results.

Data Structures

Queue, Stack
