UC2: Print a Hardcoded Palindrome Result
Goal

Display whether a predefined string is a palindrome.

Actor

User

Flow

Program starts.

A hardcoded string is stored.

The string is checked for palindrome.

Result is printed.

Program exits.

Key Concepts

Class – Container for the program logic.

Main Method – Entry point of the application.

Static Keyword – Allows method invocation without object creation.

String – Used to store textual data.

String Literal – Example: "madam".

Conditional Statement (if-else) – Used to validate palindrome logic.

Console Output – Displays results.

Data Structure

String
